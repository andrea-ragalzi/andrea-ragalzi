## Featured project

### [Document Intelligent Hub](https://github.com/andrea-ragalzi/document-intelligent-hub)

> Upload documents, ask questions and see the sources behind the answers.

A personal project where I work with FastAPI, document retrieval and LLM integrations, with a Next.js frontend.

<p>
  <a href="https://document-intelligent-hub.vercel.app"><strong>Try the demo ↗</strong></a>
</p>

**Inside the project**

* FastAPI backend for document upload, processing and question answering
* LangChain and ChromaDB for document retrieval and source-grounded answers
* Conversation history for follow-up questions
* Firebase authentication and user-scoped access to documents and conversations
* Backend tests with pytest
* Next.js frontend for managing documents and chatting with them
